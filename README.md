# ZenFlow

CRM нового поколения для массажистов, SPA и специалистов телесной терапии.
Рабочее пространство специалиста — быстро, красиво, интуитивно.

## Стек

- React 18 + Vite
- React Router (роутинг между экранами)
- Tailwind CSS (утилиты + CSS-переменные для темы)
- lucide-react (иконки)
- Fraunces / IBM Plex Sans / IBM Plex Mono (шрифты)

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

Сборка для продакшена:

```bash
npm run build
npm run preview
```

## Структура

```
src/
  theme.jsx              — контекст светлой/тёмной темы (единая точка правды)
  index.css              — CSS-переменные палитры, шрифты, анимации
  App.jsx                — роутинг
  components/
    BottomNav.jsx         — нижняя навигация (5 пунктов)
    ThemeToggle.jsx       — кнопка переключения темы для хедеров
    Switch.jsx            — переключатель для настроек
  screens/
    Dashboard.jsx         — главная: «Дыхание дня», следующий клиент, таймлайн
    Calendar.jsx          — день/неделя, перенос записи, цветные услуги
    ClientCard.jsx        — профиль клиента, рейтинг, история/оплаты/заметки/фото/рекомендации
    AppointmentForm.jsx   — создание/редактирование записи, повтор, отмена, завершение
    Finance.jsx           — доход/расход/прибыль/средний чек, график по дням
    Settings.jsx          — рабочее время, услуги, уведомления, тема
```

## Дизайн-система

Палитра и типографика заданы CSS-переменными в `src/index.css`
(`--paper`, `--surface`, `--moss`, `--clay` и т.д.), переключаются
классом `.dark` на `<html>`. Все экраны используют только эти
переменные — новый цвет темы меняется в одном месте.

Принципы интерфейса:
- максимум 5 пунктов в нижнем меню;
- любое действие — не больше 3 кликов;
- одинаковое поведение форм на всех экранах;
- крупные кнопки для работы с телефона;
- светлая и тёмная тема на всех экранах.

## Данные
